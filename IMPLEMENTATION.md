Local validation on Windows, Python 3.12.10, JAX 0.5.3, MuJoCo 3.3.5:

- `pytest -q --timeout=300`: **146 passed**.
- Real custom PPO update (64 steps) and real Orbax checkpoint round trip with
  exactly equal deterministic actions, including observation normalization.
- All three actual shipped policy checkpoints restore on CPU and produce
  finite 26-element actions from their matching environment observations.
- Real MJX evaluations of all three shipped tasks with seed 0, one episode per
  task, and a two-control-step smoke limit. Returns are finite and the reported
  reward components sum to the optimized reward.
- [Archived smoke report](myosuite/benchmarks/baselines/cpu-smoke-windows-py312.json)
  includes effective configuration, runtime metadata, seeds, per-episode results,
  and source revisions/dirty-state flags. It is a short environment regression
  reference, not a measurement of task proficiency or a retrained policy.
- Real Windows GLFW preview: two 480x640 RGB images with the seed unchanged.
- Wheel and source distribution builds passed. Installed-wheel tests from a
  temporary working directory loaded all presets/configs and the actual arm
  model, and confirmed that source-generated bytecode was excluded.
- Static Python error checks and `uv lock --check` passed. Locked CPU sync selects
  the same tested runtime dependencies; CUDA installation is explicit.

All four jobs in the fork's
[CI matrix](https://github.com/M-Colley/MyoInteract/actions/runs/39872654061)
passed on implementation commit `0209f50`: Linux and Windows on Python
3.11/3.12, including distribution and installed-wheel checks on Linux 3.11.
The subsequent follow-up adds this implementation map and smoke-report data.
The upstream
[workflow run](https://github.com/MyoInteract/MyoInteract/actions/runs/39872698951)
requires maintainer approval before executing fork workflows.

Actual CUDA/Madrona rendering has not been executed on a supported Linux GPU
runner. CPU tests verify all exposed rendering modes, model-buffer batching,
autoreset/evaluation contracts and absence of JAX tracer leaks with a renderer
test double. Historical tracked policies were not retrained. Existing motor
noise, fatigue and scientific movement metrics remain in PRs #1, #2 and #3;
this stack complements them and does not duplicate their implementations.

Final integration additionally found that the mobile/public policy normalizers
and first-layer weights expect 54 features while their historical configuration
declares 49. The saved mean/std/variance tails are exactly duplicated. [PR #10](https://github.com/MyoInteract/MyoInteract/pull/10)
reconstructs only that proven legacy feature layout, records it in the effective
configuration, preserves input files/weights, and rejects unrecognized shape
mismatches. All three actual shipped policies are checked with their restored
parameters; this is separate from the zero-policy physics smoke protocol above.
